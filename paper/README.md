# Paper Figures and Tables

This directory contains scripts to reproduce the figures and supplemental tables
for the manuscript:

> Saidin A, Ricos MG, Dibbens LM. *IUPAC consensus references improve variant
detection in clinically challenging genomic regions.* Cell Genomics. 2026.

## Figures

| Script | Output | Description |
|--------|--------|-------------|
| `figures/figure2_decomposition.py` | Figure 2 | Recall gain decomposition by aligner vs IUPAC |
| `figures/figure3_heatmap.py` | Figure 3 | Heatmap of recall gain by region/caller/type |
| `figures/figureS1_per_sample_heatmap.py` | Figure S1 | Per-sample recall gain heatmaps |
| `figures/figureS2_full_decomposition.py` | Figure S2 | Full stratification decomposition |

### Running figure scripts

All figure scripts accept `--input` (path to burden output CSV) and `--output` (path for PDF/PNG):

```bash
python paper/figures/figure2_decomposition.py \
    --input my_run/my_run_table.csv \
    --output paper/figures/figure2_decomposition.pdf
```

## Tables

Supplemental tables are generated by `calculate_fp_burden.py` batch mode:

| Table | Command | Output file |
|-------|---------|-------------|
| S1 | Per-sample output | `{prefix}_raw_per_sample.csv` |
| S2 | Aggregate median | `{prefix}_summary_median_range.csv` |
| S4 | Database-specific manifest | `{prefix}_summary_median_range.csv` |

See `examples/manifests/` for manifest templates.

## Requirements

- Python >= 3.8
- matplotlib >= 3.5.0
- seaborn >= 0.12.0
- pandas >= 1.3.0
- numpy >= 1.21.0

Install:
```bash
pip install matplotlib seaborn pandas numpy
```
